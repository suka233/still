# Still — subscription tracker for SiYuan

Track your subscriptions and free trials. Before each renewal, Still asks:
**still using it?** Keep it, cancel it, or decide later.

- Upcoming charges in the dock, the next one in the status bar
- Reminders N days before each charge, and before free trials convert
- Runs in SiYuan's kernel, so reminders are scheduled even with no window open
- Multi-currency, billing cycles of any length, month-end dates handled correctly
- Data lives in `data/storage/petal/still/` and syncs with SiYuan

Requires SiYuan 3.8.5 or later.
