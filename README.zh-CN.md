# 续了么 · Still

> 续费之前，先问你一句：**还在用吗？**

续了么帮你记下订阅和免费试用，就放在你每天用的笔记软件里。每次扣费前弹出一张卡片：**续**、**不续了**，或者**再想想**，点一下就好。支持 **Obsidian** 和**思源笔记**。

[English](README.md) · [更新日志](CHANGELOG.md) · [开发说明](docs/development.md)

![Obsidian 里的续了么](docs/media/obsidian.png)

## 功能

- **扣费前提醒**：默认提前 3 天和 1 天，免费试用转正前也会提醒；当天的提醒等到你设定的时间再发。
- **「续了么」卡片**：这一笔要扣多少、到现在大概已经付了多少。选「不续了」会把订阅标记为已取消，可以撤销，还能一键打开服务商的取消页面。
- **推送到手机**：Bark、ntfy、Telegram、Server酱（微信）、企业微信、钉钉、飞书、Discord、Slack、Gotify，或者任意 webhook。
- **侧栏一眼看清**：本月还要付多少、哪些续费等你决定、接下来扣什么；状态栏显示最近的一笔。
- **订阅管理**：月度和年度支出、已省下的钱、未来 6 个月预测、日历和分类洞察。
- **90+ 常见服务**带品牌图标；多币种按汇率合计。
- **八套主题**：五种小票风格（热敏、精品店、票根、孔版印刷、极简），加上静谧、卡片墙、时间线，都支持浅色、深色和跟随软件。
- **融入笔记**：续费和不续的决定会记进日记；任何笔记里都能放一张实时的订阅表。
- **数据归你所有**：普通 JSON 文件，存在你的库或工作空间里，怎么同步都行；支持 JSON 导出导入，两个软件格式通用。

## Obsidian

在 **设置 → 第三方插件 → 浏览** 里搜索「Still」安装。需要 Obsidian 1.8.7 或更新版本，桌面端和移动端都能用。

- 点左侧功能区的图标，或者命令「Still: 打开即将扣费」打开侧栏；「Still: 打开订阅管理」在标签页里打开管理页。
- 数据保存在库里的 `Still/` 文件夹（每条记录一个 JSON 文件）。可以在 **设置 → Still** 里改名或移动，数据会一起搬过去。
- 在任意笔记里放一张实时的即将扣费表：

  ````markdown
  ```still
  days: 30
  limit: 10
  ```
  ````

  两行都可以省略。想插入一张静态表格，用命令「Still: 插入订阅一览表」。
- **日记**：在续了么的设置里打开「写入日记」，内容会写进当天的日记，沿用「日记」核心插件的设置（文件夹、日期格式、模板）。
- **Markdown 笔记**（可选，在 设置 → Still 里打开）：在 `Still/Notes` 里为每个订阅保留一篇笔记，订阅信息写在属性里，并生成一个 `订阅.base` 视图。这些笔记由续了么维护，请在续了么里修改订阅。
- Obsidian 没有后台进程，所以提醒和推送只在某台设备开着 Obsidian 时发生；错过的会在下次启动时补上。多台设备同步同一个库时，可以在 设置 → 通知 里只让一台设备发送。

## 思源笔记

在 **集市 → 插件** 里搜索「续了么」或「Still」安装。需要思源 3.8.5 或更新版本。提醒由内核插件计算，即使窗口全部关掉也会照常提醒和推送。dock、`/续了么` 订阅表和 AI 助手工具的说明见[思源版说明](apps/siyuan/README.zh-CN.md)。

## 隐私

除了你自己配置的推送渠道，续了么只会访问公开的汇率接口（open.er-api.com / Frankfurter；在设置里关掉货币换算就不再访问）。你的订阅数据从不上传。
